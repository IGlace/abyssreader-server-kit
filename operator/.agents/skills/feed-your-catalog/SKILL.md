Each server is run by its server operator, who is responsible for what the server offers and for the data you send it.
Publish a copyright contact in your operator details.

Follow the [catalog feed guide](../../../docs/guides/catalog-feed.md). Apply
the source and rights guardrails in [AGENTS.md](../../../AGENTS.md).
Run the sample twice from the kit source tree and check that the second
import reports unchanged titles.
Verify a manual run of the adapted feed before scheduling it outside the kit.

Abyss Reader RE: is a reading tool. It has no manga of its own: it shows what the server you choose offers.
Each server is run by its server operator, who is responsible for what the server offers and for the data you send it.
The app checks that a server works as the server contract says. It does not check whether the content is lawful, and it cannot.

Publish a copyright contact in the operator details. Follow the workspace
[guardrails](../../../AGENTS.md) and the [definition guide](../../../docs/guides/publish-definition.md).
Use the invented example as a starting point. Pick the on-server or offline
signing procedure based on where the key already lives. Read its fingerprint
only. Back up the key and confirm revocations or rotations with the operator.

Verify the installed version and publish result, then have the operator open
a chapter with the app while that server is active and review the source's
health totals. The guide explains the host sandbox and version requirements.

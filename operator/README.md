# AbyssReader operator workspace

- **I use an AI agent.** Open this folder in Claude Code or Codex and say “set up my AbyssReader server.” Start with [AGENTS.md](AGENTS.md).
- **I follow steps myself.** Choose a procedure in the [operator guides](docs/guides/README.md).
- **I'm a developer.** Use the [reference](docs/reference/README.md) and [developer guides](docs/developers/README.md).

Keep your import manifests, rights records and definition sources in this
workspace on your computer. Keep server secrets on the server. The release
contains the matching installer, guides, schema and examples.

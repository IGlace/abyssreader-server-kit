# Paper Lantern Library

This fictional source demonstrates [family/source resolution](../../contract/definition-merge.md).
Its source file uses an example-domain HTTPS address. The Go test serves the HTML
fixture over local HTTPS and checks that the resolved selector identifies the
sample title. The [operator guide](../../docs/guides/publish-definition.md)
shows how to validate and sign the resolved JSON. Use your own public HTTPS
origin and authorized content when publishing a working definition.

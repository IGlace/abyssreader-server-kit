# Security policy

Use GitHub's private vulnerability reporting on the server kit repository. Choose **Security**, then **Report a vulnerability**. If you cannot use GitHub's private form, send the report to `abyss.manga@gmail.com`.

Include the affected kit version, the conditions needed to reproduce the issue, the impact and a safe way to reach you. Keep access keys, session tokens, signing keys, backups and personal data out of the report. Give the maintainers time to investigate before discussing the issue publicly.

Security fixes are released for the newest kit minor. [App support schedule](docs/guides/support-schedule.md)

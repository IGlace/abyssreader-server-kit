Follow [Share a report](../../../docs/guides/check-failures.md#share-a-report). Collect the installed kit version and health output. Ask the operator for a short excerpt of recent server or proxy logs with secrets and personal details removed. Review the excerpt for credentials before drafting.

Choose the install problem, bug or check failure form. Include the app's **Copy report for the operator** output for a check failure. Return the draft for the operator to review and submit. Use the [private reporting path](../../../SECURITY.md) for security issues and follow [AGENTS.md](../../../AGENTS.md).
